# EchoLogicer Design Spec

**Project:** Replace the current SingularityLaber studio site with a distinctly different multi-page marketing site for EchoLogicer.

**Goal:** Publish a full English-language studio website for an iOS software studio focused on IAA monetization, with a visual language that is clearly different from the existing SingularityLaber site and from the reference site.

## Brand Position

EchoLogicer is presented as a compact iOS software studio that combines product delivery, IAA monetization structure, and public-facing operational clarity. The site should read like a mobile product business with commercial discipline rather than a generic agency.

## Visual Direction

- Use a bright editorial interface instead of a dark technical lab style.
- Primary palette: warm paper backgrounds, deep graphite text, copper or amber accents, muted slate blue support tones.
- Overall feel: product operations handbook, monetization review deck, and boutique studio brochure combined.
- Avoid the existing dark neon grid style used in SingularityLaber.
- Avoid imitating the reference site's structure or visual hierarchy directly.

## Page Structure

- `index.html`: homepage with a strong brand thesis, studio positioning, service blocks, monetization workflow, and clear contact routes.
- `studio.html`: studio philosophy, operating model, audience fit, and release-support positioning.
- `services.html`: iOS product development, casual app/game support, monetization planning, release support, and public infrastructure.
- `monetization.html`: IAA philosophy, ad placement thinking, retention protection, and revenue operations.
- `contact.html`: dedicated contact page for VIP, business, and support routes.
- `privacy.html`: expanded privacy policy for websites, iOS apps, analytics, advertising, and user rights.
- `support.html`: support guidance and FAQs for product users.

## Contact Routes

- VIP: `vip@echologicer.com`
- Business: `business@echologicer.com`
- Technical support: `support@echologicer.com`

## Content Themes

- iOS software development
- mobile utility and casual app production
- IAA advertising monetization
- support-first release infrastructure
- visible business credibility through contact and policy coverage

## Testing Expectations

- Existing tests should be updated to verify the new brand, new email addresses, and continued multi-page coverage.
- The site must continue to include shared CSS and JS assets across all pages.
- Contact, support, privacy, and monetization content must retain meaningful keyword coverage.
